# Story handoffs

[Open the team story board](../github-issues/README.md) for all 16 stories, dependencies and suggested owner roles.

These files are prepared implementation handoffs. Their acceptance comes from [epics.md](../planning-artifacts/epics.md); no implementation is complete. `ready-for-dev` means prepared, while actual eligibility also requires all dependencies done. Only Story 1.1 is initially unblocked.

Use [sprint-status.yaml](sprint-status.yaml) for current implementation state. Fill a story’s implementation record during the build; do not regenerate over an active story.
