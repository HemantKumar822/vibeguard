## Problem statement

AI coding tools help people build websites quickly, but developers may miss exposed API keys, insecure configurations, and vulnerable code. Build an agent that accepts a website's source code and optionally its deployed URL, examines it for security issues, and explains what needs fixing. It should turn findings into actionable instructions and a ready-to-paste prompt for the developer's AI coding tool.

## Core capabilities

- Detect exposed secrets, API keys, and sensitive information in submitted code and browser-visible files.
- Identify issues such as missing access checks, unsafe input handling, and insecure configuration.
- Prioritise findings by severity and provide evidence, including affected files or locations, while masking secret values.
- Explain the impact and recommended fix in plain language.
- Generate a consolidated repair prompt containing relevant context, required changes, and verification steps.
- Rescan an updated submission to check whether identified issues were resolved or new ones appeared.

## Expected 24-hour prototype

Scan a deliberately vulnerable sample website, produce an evidence-backed report and repair prompt, then rescan a corrected version. For exposed credentials, include rotation or revocation in the remediation guidance.

## Evaluation

Detection accuracy, false positives, clarity of guidance, usefulness of the repair prompt, and verification of fixes.

## Safety / limitations

Only scan code and sites the team is authorised to assess. Treat automated findings as candidates for review, not guaranteed vulnerabilities.
